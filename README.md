# NotifyHub

A production-oriented email delivery, management, and tracking service built with Python and Django REST Framework.

NotifyHub provides a centralized REST API for sending and monitoring emails across multiple applications.

## Tech Stack

- Python & Django REST Framework
- PostgreSQL
- Redis & Celery
- JWT & API Key Authentication
- Docker
- OpenAPI / Swagger
- Pytest

## Planned Features

- User authentication and account management
- Application management and API keys
- Dynamic email templates
- Asynchronous email delivery
- Automatic retries and idempotency
- Email delivery, open, click, and bounce tracking
- Webhook integration
- Email history, filtering, and reporting
- API documentation
- Automated testing and Docker deployment
